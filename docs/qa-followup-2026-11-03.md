# 2026-11-03 QA 후속 수정

대상 보고서는 [초기 QA](qa-2026-10-27.md)와 [905820f QA](qa-main-905820f-2026-10-27.md)다.
현재 main의 `089c688`을 기준으로 코드를 대조했다. 기존 QA 문서는 당시 관찰 기록으로 보존한다.

| 항목 | 현재 확인과 조치 |
|---|---|
| 디버거·샘플이 main에 없음 | 과거 상태다. 현재 구현이 있으므로 새로 만들지 않았다. |
| 공용 MCP 등록·수명 관리 | 이미 구현돼 있다. 기존 등록과 종료 처리를 유지했다. |
| RCON 무응답·EOF 무한 대기 | 여전히 mcrcon의 직접 호출이었다. 전체 통신 기한·EOF 검증·실패 시 소켓 종료를 갖춘 어댑터로 교체했다. 접속자 조회는 비동기로 실행한다. |
| 로그 교체 후 앞부분 누락 | 여전히 숫자 offset만 사용했다. 파일 식별자·소비한 내용의 해시를 포함하는 cursor를 추가했다. 교체·잘림·재작성 시 처음부터 반환하고 reset을 알린다. |
| 부분 UTF-8 영구 손실 | 개행이 완성된 줄까지만 반환하고 offset을 확정하도록 수정했다. |
| 실제 paper.jar가 없어야 통과하는 시험 | 테스트 전용 외부 경로와 파일을 만들어 경로·내용 불변성을 확인하도록 수정했다. |
| late attach 후속 조회도 50ms 제한 | attach에만 짧은 기한을 적용하고 늦은 응답 이벤트를 기다린다. 후속 조회에는 정상 기한을 적용한다. 전송 계층의 같은 유형 시험도 수정했다. |
| lease 만료 시험의 타이밍 의존성 | 이번 실행에서 추가로 실패를 확인했다. 고정 sleep 대신 중단·자동 재개 이벤트로 상태 전이를 확인한다. |
| 헬퍼 종료와 강제 종료 호출의 경합 | 전체 재시험에서 이미 종료된 헬퍼의 kill 호출이 ProcessLookupError로 실패했다. terminate/kill 시 이미 종료된 경우를 허용하고, 최종 wait와 정리를 수행한다. 재현 시험을 추가했다. |

`tests/test_server_qa.py`에 추적 가능한 회귀 시험을 추가했다. 과거 QA의 미추적 `eval/qa_main.py`,
`eval/qa_server_log.py` 없이도 현재 테스트 명령으로 재현·검증한다.
새 RCON 어댑터는 기존 라이브러리와 같은 현재 수신 가능한 응답 패킷 수집 방식을 유지하며,
지연된 다중 응답의 완전성은 이번 수정 범위에 포함하지 않는다. 명령은 자동 재전송하지 않는다.

검증 명령과 로그 cursor 전환 방법은 [테스트 안내](testing.md)를 따른다.

`.cache/qa-debugger-2026-11-03.log`에 보관한다. 기존 Java 구현은 변경하지 않았다.
최초 재시험에서 발견한 lease 타이밍 실패와 헬퍼 종료 경합은 위 수정 후 최종 실행에서 통과했다.

사용자 IDE 호스트는 이번 임시 파일·루프백·독립 JVM 시험만으로 완료 판정하지 않는다.
