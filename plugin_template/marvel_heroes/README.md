# MarvelHeroes 플러그인

마블 히어로 슈트 플러그인. **아이언맨**(철 갑옷), **스파이더맨**(가죽 갑옷 풀세트), **토르**(묠니르)를 제공한다.
JDK 17, Paper API 1.20.1, Gradle Wrapper 8.14.3.

## 아이언맨 슈트

철 갑옷이 그대로 아이언맨 슈트가 된다. 별도 아이템 없이 아무 철 갑옷이나 입으면 된다.

| 부위 | 기능 |
|---|---|
| 외형 (전 부위) | 빨강·금색 아이언맨 텍스처. 헬멧 페이스플레이트·눈, 흉갑 아크 리액터, 손바닥·발바닥 리펄서 |
| 철 흉갑 | 9번 칸에 **리펄서**가 고정된다. 9번 칸을 들고 우클릭하면 하늘색 에너지 구체가 날아가고 블록·몹에 닿으면 폭발 |
| 철 부츠 | **스페이스 2번**으로 이륙한 뒤 겉날개처럼 활공. 비행 중 파란 추진 불꽃과 파란 파티클이 몸 주변에 나온다 |
| 철 부츠 (8번 칸) | 8번 칸은 비어 보이는 **추진기** 칸. 비행 중 8번 칸을 들고 우클릭하면 겉날개 폭죽처럼 가속 |

### 외형 (리소스팩)

서버 플러그인만으로는 텍스처를 바꿀 수 없으므로 리소스팩을 플러그인 jar에 넣어 두고,
플러그인이 내장 HTTP 서버(기본 포트 8765)로 접속한 플레이어에게 자동 전송한다.
클라이언트에서 "서버 리소스팩 사용"을 수락해야 적용된다. 거절했다면 `/marvelpack`.
하나의 팩에 아이언맨(철 갑옷)과 스파이더맨(가죽 갑옷) 디자인이 모두 들어 있다.

- 철 갑옷 착용 모델(`iron_layer_1/2.png`)과 철 갑옷 아이템 아이콘 4종을 교체한다.
- 리펄서 아이템(바다의 심장 + CustomModelData 7001)은 빨간 장갑·하늘색 손바닥 아이콘으로 보인다.
- 추진기 아이템(폭죽 탄약 + CustomModelData 7002)은 완전히 투명해서 8번 칸이 비어 보인다.
  리소스팩을 받지 않으면 폭죽 탄약 아이콘으로 보인다.
- 텍스처는 [tools/gen_hero_textures.py](tools/gen_hero_textures.py)에 픽셀 단위로 정의되어 있다
  (바닐라 에셋 미사용). 수정 후 `python plugin_template/marvel_heroes/tools/gen_hero_textures.py`
  (Pillow 필요)를 실행하고 다시 빌드한다.
- 다른 PC의 클라이언트가 접속한다면 `config.yml`의 `resource-pack.public-host`를 서버 PC의 IP로 바꾸고
  방화벽에서 8765 포트를 연다.

### 리펄서 (철 흉갑)

- 흉갑을 입으면 9번 칸에 리펄서가 들어간다. 원래 있던 아이템은 인벤토리 빈칸으로 옮겨지고, 자리가 없으면 발밑에 떨어진다.
- 착용 중에는 9번 칸에 아이템을 넣거나 리펄서를 빼낼 수 없다(클릭, 숫자키 9, 드래그, Q 버리기, F 손 바꾸기 모두 차단).
- 흉갑을 벗으면 리펄서는 사라지고 9번 칸이 다시 일반 칸이 된다. 사망 시 드롭되지 않는다.
- 발사체: 회전하는 하늘색 파티클 구체 + 꼬리, 속도 1.8블록/틱, 최대 40틱(약 72블록).
  블록이나 생물·탈것에 닿으면 섬광·스파크와 함께 위력 2.0 폭발. 시전자는 자기 폭발에 피해를 입지 않는다.
- 기본값은 **블록 파괴·화재 없음**(`repulsor.break-blocks`, `repulsor.set-fire`로 변경).

### 비행 (철 부츠)

- 부츠를 신으면 8번 칸이 추진기 칸으로 잠긴다(9번 칸 리펄서와 같은 방식: 기존 아이템은 옮겨지고, 넣기·빼기·버리기 차단,
  벗으면 해제). 빈손 우클릭은 클라이언트가 서버에 알리지 않아서, 투명한 아이템을 넣어 비어 보이게 한 것이다.

- 서바이벌·어드벤처 모드에서 동작한다(크리에이티브는 원래의 크리에이티브 비행 유지).
- 땅에서 스페이스 2번 → 파란 고리와 함께 위로 솟구친 뒤 약 0.35초 후 활공 상태로 전환된다. 겉날개가 없어도 된다.
- 비행 중 스페이스 2번 → 바라보는 방향으로 가속(쿨다운 0.6초).
- 비행 중 Shift → 활공 해제(낙하). 착지하거나 물에 들어가면 비행이 끝난다.
- 비행 중 **8번 칸을 들고 우클릭** → 겉날개 폭죽과 같은 가속. 실제 폭죽 로켓(폭발 효과 없음)을 플레이어에게 붙이는
  방식이라 바닐라와 똑같이 몇 초간 바라보는 방향으로 밀어 준다(`flight.thruster-power` 1~3, 쿨다운 0.5초).
  땅에서 누르면 "비행 중에만 쓸 수 있습니다" 안내만 나온다.
- 비행 중과 착지 직후 1초간 낙하·벽 충돌 피해를 받지 않는다(`flight.negate-fall-damage`).

## 스파이더맨 슈트

가죽 갑옷 4종(헬멧·흉갑·레깅스·부츠, 색 무관)을 **모두** 입으면 스파이더맨이 된다. 하나라도 벗으면 모든 능력이 꺼진다.
`/kit spiderman`으로 세트를 받는다.

**외형 (리소스팩)**: 가죽 갑옷이 빨간 거미줄 무늬 + 가슴 거미 엠블럼 + 큰 흰 눈 마스크 + 파란 옆구리·다리의
스파이더맨 슈트로 보인다. 아이템 아이콘 4종도 바뀐다. 가죽 갑옷은 기본 층에 염색 색이 곱해지고 덧씌움(overlay) 층은
그대로 그려지므로, 기본 층(`leather_layer_*.png`, `leather_*.png`)은 비우고 디자인을 덧씌움 층(`*_overlay.png`)에만
그렸다. 그래서 **어떤 색으로 염색한 가죽 갑옷이든** 같은 스파이더맨 디자인으로 보인다
(리소스팩이 없으면 바닐라 가죽 갑옷 + 염색 색).

| 능력 | 동작 |
|---|---|
| 괴력 | 근접 공격(휩쓸기 포함) 피해 **4배** (`spiderman.attack-multiplier`) |
| 벽 타기 | 바로 앞의 벽을 바라보면 자동으로 오른다. 꼭대기에서는 한 번 살짝 뛰어 올라선다. 공중에서 Shift = 벽에 매달려 멈춤, 벽에서 고개를 돌리면 떨어진다 |
| 웹 슈터 (9번 칸) | 9번 칸은 비어 보이는 웹 슈터 칸. 9번 칸을 들고 우클릭하면 거미줄이 날아간다(사거리 약 40블록) |
| 끌어당기기 | 거미줄이 **엔티티**에 붙은 상태에서 다시 우클릭 → 그 엔티티를 자기 앞 2블록으로 끌어온다 |
| 거미줄 이동 | 거미줄이 **블록**에 붙은 상태에서 다시 우클릭 → 그 위치로 날아간다. 벽이면 벽에 붙고 벽 타기로 이어진다 |

- 붙은 거미줄은 15초 동안 유지되고(`spiderman.web.attach-seconds`), 48블록 이상 멀어지거나 대상이 사라지면 끊어진다.
  유지되는 동안 손에서 대상까지 흰 거미줄 파티클이 보인다.
- 웹 슈터 칸은 아이언맨 칸과 같은 방식으로 잠긴다(기존 아이템은 옮겨지고, 넣기·빼기·버리기 차단).
  빈손 우클릭은 서버에 전달되지 않아서 투명한 아이템(종이 + CustomModelData 7003)을 넣어 비어 보이게 한다.
- 거미줄 이동 중과 끝난 뒤 2초간은 낙하 피해를 받지 않는다. 벽 타기 자체에는 낙하 피해 보호가 없다.
- 1.20.1 서버는 이동 키 입력을 알 수 없으므로, 벽 타기는 "벽을 바라보고 있는가"로 판단한다.

## 토르 (묠니르)

1.20.1에는 철퇴(mace) 아이템이 없으므로(1.21에서 추가), 철 검에 리소스팩 모델을 입힌 **묠니르** 커스텀 아이템을 쓴다.
`/kit thor`로 받는다. 부서지지 않는다.

| 동작 | 결과 |
|---|---|
| 묠니르를 들고 우클릭 | 망치가 회전하며 바라보는 방향으로 날아간다(1.8블록/틱). 처음 맞은 몹에 피해 10 + 넉백 후 그 자리에 멈춰 떠 있다. 블록에 맞거나 40블록을 날아가도 멈춘다 |
| 던진 상태에서 다시 우클릭 | 망치가 플레이어에게 돌아온다(2.0블록/틱). **블록을 뚫고** 오며, 돌아오는 길의 몹에도 피해 10(던질 때 맞은 몹은 제외) |

- 던진 동안 손 칸에는 같은 아이템이 "던짐" 상태(희미한 윤곽선 아이콘)로 남는다. 빈손 우클릭은 서버에 전달되지 않으므로
  이 아이템을 우클릭해서 회수한다. 던진 상태에서는 옮기기·버리기·손 바꾸기가 막힌다.
- 날아가는 망치는 아이템 디스플레이 엔티티(저장되지 않음)다. 플레이어가 나가거나 다른 월드로 가면 바로 손으로 돌아오고,
  서버가 재시작되면 "던짐" 상태 아이템은 자동으로 원래대로 돌아온다. 죽으면 떨어진 묠니르도 원래 상태가 된다.
- 리소스팩이 없으면 철 검으로 보인다.

## 명령어

| 명령어 | 권한 | 설명 |
|---|---|---|
| `/kit ironman` (`/kit 아이언맨`) | `marvel.kit` (모두) | 이름 붙은 철 갑옷 세트 지급 |
| `/kit spiderman` (`/kit 스파이더맨`) | `marvel.kit` (모두) | 빨강·파랑 가죽 갑옷 세트 지급 |
| `/kit thor` (`/kit 토르`) | `marvel.kit` (모두) | 묠니르 지급 |
| `/kit <히어로> <플레이어>` | `marvel.kit.others` (OP) | 다른 플레이어에게 지급 |
| `/marvelpack` | `marvel.pack` (모두) | 리소스팩 다시 받기 |

`/kit`을 이미 다른 플러그인(예: SimpleKit)이 쓰고 있으면, 서버 시작 직후 MarvelHeroes가 `/kit`을 가져온다.
히어로 이름 없이 `/kit`만 입력하면 원래 플러그인의 `/kit`이 그대로 실행된다(`/simplekit:kit`도 그대로 동작).

## 빌드

저장소 루트에서:

```powershell
.\plugin_template\marvel_heroes\gradlew.bat -p plugin_template/marvel_heroes build
```

JAR: `plugin_template/marvel_heroes/build/libs/MarvelHeroes.jar` (리소스팩 `marvel_pack.zip` 포함).

## 설치와 확인

1. JAR를 `mc_server/plugins/`에 복사하고 Paper 서버를 (재)시작한다.
2. 로그에 `Serving Iron Man resource pack at http://127.0.0.1:8765/...`와
   `MarvelHeroes enabled`가 출력되는지 확인한다.
3. 접속 시 리소스팩 수락 → `/kit ironman` 또는 `/kit spiderman` → 갑옷 착용.

## 설정 (`plugins/MarvelHeroes/config.yml`)

| 키 | 기본값 | 설명 |
|---|---|---|
| `resource-pack.enabled` | `true` | 리소스팩 전송 여부 |
| `resource-pack.port` / `public-host` | `8765` / `127.0.0.1` | 내장 HTTP 서버 포트와 클라이언트가 접속할 주소 |
| `resource-pack.url` | `""` | 외부에 올린 팩 URL (비우면 내장 서버) |
| `resource-pack.force` | `false` | 거절 시 접속 종료 |
| `repulsor.cooldown-ms` | `350` | 발사 쿨다운 |
| `repulsor.speed` / `max-ticks` | `1.8` / `40` | 속도·사거리 |
| `repulsor.explosion-power` | `2.0` | 폭발 위력 |
| `repulsor.break-blocks` / `set-fire` | `false` / `false` | 블록 파괴·화재 |
| `flight.launch-power` / `boost-power` | `1.3` / `1.7` | 이륙·가속 세기 |
| `flight.boost-cooldown-ms` | `600` | 가속 쿨다운 |
| `flight.glide-delay-ticks` | `7` | 이륙 후 활공 전환까지 틱 |
| `flight.thruster-power` | `2` | 8번 칸 추진기 폭죽 체공 시간(1~3) |
| `flight.thruster-cooldown-ms` | `500` | 추진기 쿨다운 |
| `flight.negate-fall-damage` | `true` | 낙하·벽 충돌 피해 무시 |
| `spiderman.attack-multiplier` | `4.0` | 근접 공격 피해 배율 |
| `spiderman.climb-speed` | `0.22` | 벽 오르는 속도(블록/틱) |
| `spiderman.web.speed` / `max-ticks` | `2.5` / `16` | 거미줄 속도·사거리 |
| `spiderman.web.cooldown-ms` | `300` | 발사 쿨다운 |
| `spiderman.web.attach-seconds` / `max-length` | `15` / `48` | 붙은 거미줄 유지 시간·최대 길이 |
| `spiderman.web.pull-speed` / `zip-speed` | `1.2` / `1.4` | 끌어당기기·거미줄 이동 속도(블록/틱) |
| `thor.throw-speed` / `return-speed` | `1.8` / `2.0` | 묠니르 날아가는·돌아오는 속도(블록/틱) |
| `thor.max-distance` | `40` | 이 거리를 날아가면 멈춤 |
| `thor.damage` | `10.0` | 맞은 몹이 받는 피해 |
| `debug` | `false` | 비행·거미줄·벽 타기·공격 배율 동작을 서버 로그에 기록 |

이미 생성된 `config.yml`에는 새 키가 자동으로 추가되지 않는다. 없는 키는 위 기본값으로 동작한다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `MarvelHeroesPlugin` | 진입점, 모듈 등록 |
| `ResourcePackHost` | jar 안의 리소스팩을 HTTP로 제공하고 접속 시 전송 |
| `KitCommand` | `/kit <히어로>` (기존 `/kit` 소유 플러그인으로의 위임 포함) |
| `SuitSlots` | 히어로별 잠긴 핫바 칸(리펄서·추진기·웹 슈터) 관리 |
| `ironman/IronManSuit` | 슈트 판정, 리펄서 아이템 생성·식별 |
| `ironman/RepulsorGauntlet` | 리펄서 우클릭 발사, 자폭 피해 방지 |
| `ironman/RepulsorBolt` | 리펄서 발사체(레이 트레이스 이동, 파티클 구체, 폭발) |
| `ironman/FlightBoots` | 더블 점프 이륙, 겉날개 없는 활공, 가속, 8번 칸 추진기, 파티클, 낙하 피해 무시 |
| `thor/ThorHammer` | 묠니르 아이템(일반/던짐 상태) |
| `thor/Mjolnir` | 던지기·멈춤·회수, 아이템 디스플레이 이동·회전, 던짐 상태 보호 |
| `spiderman/SpiderSuit` | 슈트 판정(가죽 풀세트), 웹 슈터 아이템, 염색 세트 |
